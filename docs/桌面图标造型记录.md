## 当前版本（1.2.15+）技术细节

### 资源结构
官方 Android Studio 模板布局，位图放 `mipmap-*dpi`：

```
app/src/main/res/
├── mipmap-anydpi-v26/
│   ├── ic_launcher.xml          <adaptive-icon> 三层
│   └── ic_launcher_round.xml
└── mipmap-{m,h,xh,xxh,xxx}dpi/
    ├── ic_launcher_background.png    108dp 画布，背景层
    ├── ic_launcher_foreground.png    108dp 画布，前景层（RGBA）
    ├── ic_launcher_monochrome.png    108dp 画布，主题图标层（Android 13+）
    ├── ic_launcher.png               48dp，legacy 方形
    └── ic_launcher_round.png         48dp，legacy 圆形
```

`adaptive-icon` 三层引用：

```xml
<background android:drawable="@mipmap/ic_launcher_background" />
<foreground android:drawable="@mipmap/ic_launcher_foreground" />
<monochrome android:drawable="@mipmap/ic_launcher_monochrome" />
```

> `monochrome` 是 Android 13+ 的主题图标层，只保留螺旋轮廓（纯白 + alpha），由系统按壁纸取色着色。1.2.14 及之前没有这一层。

### 图形规格

| 项 | 值 |
|---|---|
| 前景画布 | 108dp（自适应图标标准） |
| 可见遮罩 | 中心 72dp（launcher 的 squircle / 圆形掩码） |
| 图形占比 | 画布的 **76%**（`CONTENT_SCALE`），居中 |
| 背景渐变 | 135° 线性，三段 `#284252` → `#376049` → `#3B7538` |
| 前景颜色 | 冷白 `#C6D0CE` → 纯白 `#FFFFFF`（保留陶瓷质感明暗） |
| 投影 | 半透明黑，强度 0.55，仅在螺旋邻域内衰减 |

**为什么是 76%**：launcher 只显示 108dp 画布的中心 72dp。图形放大到 82% 时外圈白环会被掩码切掉一截；76% 时外圈刚好贴边、完整可见，留白也和原图一致。

### 生成方式

源图 `docs/icon-src/launcher-source.jpg`（用户提供的 1920×1919 照片）→ `tools/gen_launcher_icon.py` 自动生成全部 PNG。

```bash
python3 tools/gen_launcher_icon.py --scale 0.76              # 写入正式资源
python3 tools/gen_launcher_icon.py --scale 0.76 --preview-only  # 只出预览
```

脚本做了三件事：

1. **背景分离** —— 源图背景是绿→蓝对角渐变带暗角，用三次多项式拟合背景模型（拟合误差 MAE ≈ 2/255），螺旋区域用模型补全。
2. **螺旋抠图** —— 按「像素亮度相对本地背景的亮度」求软边 alpha，边缘不锯齿；投影（比背景暗的部分）单独抽成半透明黑层，与螺旋做 source-over 烘进同一张前景 RGBA，**保证投影随螺旋同步缩放、任何机型都不错位**。
3. **明暗保留** —— 前景颜色不是纯白平涂，而是按源图像素亮度在 `#C6D0CE`～`#FFFFFF` 之间插值，保留陶瓷质感的立体感。

预览图输出到 `build/icon-preview-scale*.png`（108dp 画布 + 72dp 圆形掩罩）。

### 回滚方法

**回到 1.2.14 的蓝渐变 Wi-Fi 图标**：

```bash
cp docs/icon-archive/v1.2.14-blue-wifi/ic_launcher_background.xml \
   docs/icon-archive/v1.2.14-blue-wifi/ic_launcher_foreground.xml \
   app/src/main/res/drawable/
cp docs/icon-archive/v1.2.14-blue-wifi/ic_launcher.xml \
   docs/icon-archive/v1.2.14-blue-wifi/ic_launcher_round.xml \
   app/src/main/res/mipmap-anydpi-v26/
for d in mdpi hdpi xhdpi xxhdpi xxxhdpi; do
  cp docs/icon-archive/v1.2.14-blue-wifi/mipmap-$d/*.png app/src/main/res/mipmap-$d/
done
rm -f app/src/main/res/mipmap-*dpi/ic_launcher_background.png \
      app/src/main/res/mipmap-*dpi/ic_launcher_foreground.png \
      app/src/main/res/mipmap-*dpi/ic_launcher_monochrome.png
```

或直接 `git checkout 8e3f78a -- app/src/main/res/`（1.2.14 的资源状态）。

**回到 1.2.5 的绿渐变 + Wi-Fi 弧线矢量**：见 git `af12909`。

## 已知问题

- 自适应图标用了位图而非矢量，包体从 159 KB 涨到 427 KB（PNG 占主要体积）。可接受，但若要瘦身可改成矢量路径（螺旋曲线用 `path` 描摹，精度会下降）。
- `ic_launcher_background.xml`（矢量渐变）已随位图方案一并删除；背景实际生效的是 PNG。
